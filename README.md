Classic Forever Beta için Hunter 1-30 rehberinin tek sayfalık, gayriresmî Türkçe özeti.
Tek dosya: `index.html` (CSS ve JS gömülü, dış bağımlılık yok).
Bölümler: genel bakış, talent dağılımı (21/0/0), ırk seçimi, rotasyon, ipuçları, stat önceliği, grup ve makrolar.
Kaynak: Mobalytics Hunter Leveling Guide (bağlantı sayfanın altında).
Açmak için `index.html` dosyasını tarayıcıda çift tıkla.
